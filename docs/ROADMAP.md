# Roadmap

## Фаза 1 — MVP (готово в этом репозитории)

- [x] Точные (побайтовые) дубликаты среди обычных файлов
- [x] Точные дубликаты внутри архивов (.zip/.tar(.gz)/.7z/.rar\*) и
      "вперемешку" с обычными файлами
- [x] Двухступенчатое хэширование (quick + full) для скорости на больших
      файлах/дисках
- [x] Карантин с manifest.json, без автоматического удаления
- [x] Отдельная, более осторожная обработка медиафайлов (фото/видео)
- [x] Веб-интерфейс для запуска скана и review с превью изображений
- [x] CLI для скриптования/автоматизации
- [x] Тесты на сканер, архивы, дедупликацию и карантин

\* `.rar` требует внешнюю утилиту `unrar`/`unar` в PATH.

## Фаза 2 — Near-duplicate медиа + лица + альбомы (архитектура заложена, не реализовано)

Интерфейсы уже описаны в `src/dupecleaner/media.py`, чтобы фаза 2 не
требовала переделки конвейера:

- [ ] Near-duplicate фото (`imagehash`, perceptual hashing) — разные
      разрешения/пережатия/лёгкое редактирование одного и того же кадра
- [ ] Near-duplicate видео (сэмплирование кадров + агрегированный
      perceptual hash)
- [ ] Распознавание лиц полностью офлайн (`face_recognition`/`insightface`,
      без каких-либо облачных API) и кластеризация по персонам
- [ ] Авто-подбор названий альбомов (дата + геолокация по EXIF, офлайн
      reverse-geocoding + кластеры лиц) — только как предложение,
      подтверждаемое пользователем, а не автоматическое перемещение
- [ ] UI: разметка "кто есть кто" один раз, дальше используется повторно

## Фаза 3 — Облака и синхронизация (план)

- [ ] Индексация содержимого облачных хранилищ (Google Drive/Photos,
      Яндекс.Диск, OneDrive, Dropbox) через их официальные API — только
      метаданные и хэши, не постоянная выгрузка содержимого
- [ ] Сопоставление "то же самое" между локальным диском и облаком
      (используя тот же движок дедупликации)
- [ ] Явно управляемая синхронизация ("оставить только в облаке",
      "оставить только локально", "оставить в обоих") — снова без скрытых
      автоматических удалений

## Осознанно не в скоупе (пока)

- Мобильное приложение — веб-интерфейс покрывает review-сценарий с ПК;
  вернуться к вопросу, если понадобится review прямо с телефона.
- Обучение собственной модели для распознавания лиц — готовых офлайн
  библиотек достаточно для личного архива.
